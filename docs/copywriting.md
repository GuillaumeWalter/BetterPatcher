# Easy Patch | Copywriting

UI and marketing copy: **English only**. Deploy on **Vercel**.

## Punctuation (no dashes in prose)

Do not use `-`, `–`, or `—` to join clauses or as decorative separators in sentences or UI strings.

Use instead:

| Device | Use for |
|--------|---------|
| `:` | Introduce or explain |
| `( )` | Aside, clarification |
| `/` | Short alternatives (Solo / Pro) |
| `\|` | Compact labels / titles |
| `·` | Light inline lists or meta separators (Trial · Solo · Pro) |

OK: technical names, code, URLs, `€4.99 / month`.

### Examples

- Bad: `Card required — no charge today`
- Good: `Card required (no charge today)`
- Bad: `Easy Patch — Patch notes`
- Good: `Easy Patch | Patch notes`
- Good: `Trial · 5 generations · card required`
