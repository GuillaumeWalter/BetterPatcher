# Easy Patch | Project context

## Vision

SaaS that turns commits (and later tickets) into structured patch notes and ready-to-publish social posts for indies, studios, live ops, and eng / product marketers.

## Stack

- Next.js App Router + TypeScript + Tailwind + shadcn/ui
- Auth.js (GitHub login) · optional GitLab OAuth link for import
- Stripe (trial card verification + Solo / Pro subscriptions)
- Supabase (profiles, quotas, patch note history, GitLab tokens)
- Vercel AI SDK (Gemini / AI Gateway)
- Hosting: Vercel

## Pricing (summary)

- Trial: €0, card required, 5 one-time generations
- Solo: €4.99 / month, 25 generations, 1 user
- Pro: €9.99 / month, 80 generations, team seats (copy ready; real invites later)

## Current sources

GitHub import · GitLab import · manual paste
