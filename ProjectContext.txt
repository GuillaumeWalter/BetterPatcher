# Easy Patch | Project context

## Vision

SaaS that turns commits (and ticket keys) into structured patch notes and ready-to-publish social drafts for indies, studios, live ops, and eng / product marketers.

## Stack

- Next.js App Router + TypeScript + Tailwind + shadcn/ui
- Auth.js (GitHub login) · GitLab OAuth · Linear OAuth
- Stripe (trial card verification + Solo / Pro subscriptions, annual)
- Supabase (profiles, quotas, patch notes, platform drafts, team seats)
- Vercel AI SDK (Gemini)
- Hosting: Vercel · Netlify-ready docs in agent skills

## Pricing (summary)

- Trial: €0, card required, 5 one-time generations
- Solo: €4.99 / month, 25 generations, 1 user
- Pro: €9.99 / month, 80 generations, team seats (invites + shared quota + shared history)

## Core product (v0.6 — complete)

- AI patch note generation (streaming)
- Share Studio: edit markdown, per-platform drafts, copy, regenerate one/all
- Discord webhook publish + Discord bot
- GitHub / GitLab import, manual paste
- Linear ticket title enrichment
- Guided onboarding after trial activation
- History (personal + Pro team read/copy)
- Billing, emails, RGPD delete, PWA, Sentry

## Next (post-core)

- Jira integration
- Social OAuth publish (Meta, X, LinkedIn)
- Brand voice memory

Done in v0.7: Discord schedule (cron), GitHub Action on release/tag
